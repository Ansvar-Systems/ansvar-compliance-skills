# v2.6.0 submission packet

Status: release candidates. Local packaging checks establish source identity and
archive integrity; they do not establish portal acceptance or installed-client
behaviour. Merging publishes the custom Claude marketplace. Claude directory and
ChatGPT publication remain separate portal actions.

## What changed

Zero Trust and Vulnerability Management move to compiled skill 1.3.0
(`ansvar-workflow-mcp#505`, published by `ansvar-ai#1202` and deployed by
`deploy#4591`):

- Zero Trust asks six numbered evidence batches—one for each of five pillars
  and one cross-cutting batch—instead of a separate question and confirmation
  for each of 40 functions.
- Vulnerability Management asks three evidence batches instead of repeating the
  interview for each of nine functions.
- The findings review exposes every proposed stage or compliance level in one
  table so the person can correct it before approval.
- Every below-target item separates the action from its `done_when` evidence;
  each P1 explains the risk that makes it first.
- Programme reports use maturity/compliance language, carry red-team challenges,
  and reconcile one fail-closed verification state across report and receipt.
- The receipt says the HTML report link lasts one hour and explains how to obtain
  a fresh link without spending another assessment run.

Every other workflow-library skill changes only its generated build identity.
All Claude plugins move to 2.6.0; the ChatGPT batch rebuilds at 0.6.0.

## Claude listing fields

All four marketplace entries use version 2.6.0. Existing descriptions remain
unchanged. Replace the Zero Trust and Vulnerability Management effort copy with:

- Zero Trust: expect 20 to 35 minutes with records at hand; six evidence
  batches, one findings review, about 230 source and control-library lookups,
  with some tool work taking 15 to 25 minutes.
- Vulnerability Management: expect 15 to 25 minutes with records at hand;
  three evidence batches, one findings review and about 30 source and
  control-library lookups.

Zero Trust prompts:

- Using Ansvar, assess our zero trust maturity for the systems we name.
- Using Ansvar, re-run our zero trust assessment with baseline_report_id <report id from our previous receipt> and show what changed.
- Using Ansvar, identify which open zero trust gaps relate to NIS2 Article 21.

Vulnerability Management prompts:

- Using Ansvar, assess our vulnerability management process. We make industrial gateways sold in Germany and the Netherlands.
- Using Ansvar, run this week's vulnerability cycle for the components in our SBOM and tell me what is on the KEV list.
- Using Ansvar, which new vulnerabilities since our last cycle affect our products, and which can an attacker reach? Here is the cursor from last time.
- Using Ansvar, re-run our vulnerability management assessment with baseline_report_id <the report id from our last receipt> and show which gaps closed.
