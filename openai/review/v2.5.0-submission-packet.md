# v2.5.0 founder submission packet

Status: release candidates. Local packaging checks do not establish portal
acceptance or installed-client behavior. Expected review outcomes are test
specifications. The founder submits and publishes after review. Merging
publishes the custom Claude marketplace; directory publication is separate.

## What changed

The Zero Trust and Vulnerability Management skills move to compiled skill
1.1.0 (ansvar-workflow-mcp#497, re-pinned on ansvar.eu by ansvar-ai#1188):

- A plain-language preflight before the first question: what the run covers,
  what it costs on the plan, how many replies and checkpoints Ansvar's own run took, what to have
  ready and what the report contains.
- Grounding (architecture workspace or interview) stated in the agent's own
  words, never submitted as a field.
- Zero trust: the target stage per pillar explained in plain words and chosen
  by the person.
- Vulnerability cycle: the first run keeps `watermark_cursor` from snapshot
  page 1; later runs read one `source="all"` cursor; product searches use NVD
  vendor and product names; every component also gets a national-advisory
  search.
- Every function records priority, effort, the regulations evaluated and
  whether each applies.

Every other library skill changes only its build identity. All Claude
plugins move to 2.5.0; the ChatGPT batch rebuilds at 0.5.0.
