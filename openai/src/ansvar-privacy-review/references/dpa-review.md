# DPA review dimensions

This is a review agenda, not a legal checklist with presumed conclusions.
Fetch the applicable text and record exceptions for the actual parties and scope.

| Dimension | Evidence to inspect |
|---|---|
| Roles and processing description | Controller/processor roles; subject matter, duration, purpose, data categories and affected groups; completed schedules |
| Instructions and confidentiality | Documented instructions, duties of authorized personnel, treatment of an unlawful instruction |
| Security | Concrete measures, responsibilities, assurance evidence and how changes are communicated |
| Subprocessors | Authorization mechanism, notice, objection process, downstream obligations and accountability |
| Assistance | Rights requests, security incidents, DPIAs and consultation; allocations and practical procedures |
| Incident handling | Notification trigger, parties, information, escalation and cooperation; distinguish processor-to-controller duties from controller-to-authority deadlines |
| Return and deletion | End-of-service instructions, copies, retention exceptions, backups and evidence of completion |
| Assurance and audits | Information access, audit rights, conditions and restrictions that affect the stated rights |
| International transfers | Countries, recipients, remote access, transfer mechanism and necessary supporting assessment |
| Contract consistency | Conflicts across main terms, schedules and referenced policies; order of precedence; unresolved missing material |

Do not turn a standard controller notification deadline into a universal
processor deadline. Do not infer adequate security from a certification logo
or assume that signing transfer clauses resolves the entire transfer analysis.
